## Description

### What changed
- enforce a strict single-page BrowserContext policy so ad/RTB tabs are closed at creation, before `about:blank` can navigate to domains such as adtarget.biz or monetixads.com
- retry exact VINTED_MODEL persistence without weakening target identity; when Vinted drops the selected state, retries use another independently verified exact row and may recover only with the same collection id proven from that row
- classify an explicitly visible `Sprzedane` / `Sold` item as UNAVAILABLE instead of CANNOT_NEGOTIATE
- add a portfolio-grade root README, architecture overview, demo section and a `docs/media` guide for a short video plus screenshots

### Fresh-log evidence
- active negotiation listing 975 / marketplace 9717432736 remains persisted and the seller message `1500?` schedules the next policy decision for 03:14:38
- market observer is working, but iPhone 13 Pro Max and iPhone 15 Pro Max occasionally lose `brand_collection_ids[]` after an exact row is clicked
- user screenshots prove extra browser tabs are real advertising/RTB redirects even though the previous guard usually did not log them before teardown

### Safety
- no semantic fallback was added to VINTED_MODEL
- exact collection-id URL recovery is allowed only after the id was parsed from an independently proven exact selectable row
- sold/unavailable listings are persisted as terminal state rather than deleted, preserving history
- quota, persistent action guards, audit and submission ordering are unchanged
