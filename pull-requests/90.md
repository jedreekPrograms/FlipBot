## Description

Stage 9 hardens only the isolated PRICE_PROBE test runtime. Normal Vinted catalog/negotiation flows are untouched.

Findings:
- the explicit vinted.pl prohibition compared the literal URI host, so a DNS-root-dot FQDN such as `www.vinted.pl.` was not recognized even though it is DNS-equivalent to `www.vinted.pl`;
- every PRICE_PROBE click/text interaction already passes through PriceProbeTestHumanPacing, but when pacing was disabled that helper performed no origin enforcement, and with pacing enabled a redirect could happen during the intentional delay before the caller clicked the locator.

Fix:
- canonicalize trailing DNS root dots before checking the explicit vinted.pl/subdomain prohibition;
- validate the configured non-Vinted probe endpoint before every probe click and text entry even when optional human pacing is disabled;
- when pacing is enabled, revalidate the endpoint after the delay/hover before control returns to the actual click;
- during paced text entry, revalidate before each character so a mid-typing navigation stops the controlled test interaction fail-closed;
- add regression tests for `vinted.pl.` / `www.vinted.pl.` including direct-config scope checks.

No selector, real-offer, quota, guard, database, backend, frontend, or normal Vinted worker behavior changes.
