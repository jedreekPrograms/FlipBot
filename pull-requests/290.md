## Description

## Goal

Allow editing S24/S25/etc. negotiation prices, acceptance thresholds, messages, step count, adaptive mode, global cap and response rules even while conversations are active, without changing the meaning of any already-started negotiation.

## Design

- Every main/additional product has a monotonic `negotiationStrategyVersion`.
- When the first real offer starts a conversation, the backend pins an immutable JSON snapshot of:
  - adaptive pricing mode
  - global max negotiation price
  - all negotiation steps
  - accepted-counter thresholds
  - messages
  - rejection/counteroffer policies and waits
- Existing negotiations use their pinned snapshot in Playwright.
- New negotiations use the latest saved product strategy.
- Legacy active negotiations are backfilled on startup before the app becomes ready.
- Safe rediscovery of untouched listings clears any stale snapshot so a future new conversation pins the then-current version.

## Safety behavior

- Raising the current global cap never expands an old conversation.
- Lowering the current cap remains a safety brake for older adaptive conversations while the product remains in adaptive mode.
- Shared Vinted account identity is still locked while any negotiation is active.
- Product category/brand/model/search identity is still locked while that product has active negotiations.
- The 25/day quota and real-action guards are untouched.

## UI

- Main/additional strategy fields are editable while active conversations exist.
- UI explains that the save creates a new version for future conversations.
- Additional-product target identity is disabled while that product has active negotiations.
- Buy-candidate and History views show the negotiation strategy version.

## Schema

Adds V47 plus a startup schema initializer because Flyway is disabled in the local profile.

## Tests

Includes regression coverage for:
- immutable snapshot after live config mutation
- old runtime conversation uses pinned ladder/messages
- increased live cap does not expand old conversation
- lowered live cap acts as a safety brake
- main active negotiation can create a new ladder/message version
- additional-product active negotiation can create a new strategy version while target identity remains locked
