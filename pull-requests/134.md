## Description

## What changed
- split bot activity into active negotiations, negotiations started today, and next steps executed today for new vs older negotiations
- expose `/api/bots/{botId}/activity/today` with day boundaries fixed to `Europe/Warsaw`
- refresh daily activity and quota on the Bots page every 5 seconds instead of only on page load/manual refresh
- rename the misleading `Dzisiejsze oferty` column to `Limit dzienny`
- show confirmed, ambiguous and currently unattributed quota usage separately

## Daily limit correctness
- bind every new quota reservation to the persistent real-action guard `requestId`
- retrying the same reservation is idempotent and cannot increment `/25` twice
- releasing the same reservation twice is idempotent and cannot decrement `/25` twice
- an audited `CONFIRMED` or `AMBIGUOUS` action cannot be released
- rebuild/repair quota undercounts from the union of durable audit request IDs and active reservation request IDs, without double-counting request IDs present in both
- keep conservative overcounts visible as `W toku / bez audytu` instead of silently lowering a safety limit
- write quota reservation and real-action audit timestamps explicitly in `Europe/Warsaw`
- add migration `V36__make_daily_offer_quota_idempotent.sql` for the request-id reservation ledger

## Daily metrics
- active negotiations: current `NEGOTIATING` rows
- new negotiations today: distinct confirmed `FIRST_OFFER` actions since 00:00 Europe/Warsaw
- next steps today: confirmed `NEXT_STEP` actions, split between negotiations started today and older negotiations
- `/25`: conservative safety quota for all real offer actions (`FIRST_OFFER` + `NEXT_STEP`), not a count of new negotiations

## Tests
- configured quota limit
- audit + reservation ledger union without duplicate request IDs
- quota undercount repair
- hard-limit refusal after reconciliation
- idempotent reservation replay
- idempotent repeated release
- audited reservation cannot be released
- release deactivates only its own unaudited reservation
- daily activity split between negotiations started today and older negotiations
