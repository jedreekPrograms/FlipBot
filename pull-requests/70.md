## Description

### Why
Vinted can render the informational `Weryfikacja Elektroniki` modal on catalog pages. Its `electronics-verification-pop-up-dialog--overlay` covers the catalog and intercepts pointer events, which can make category/brand/model filtering time out even though the underlying controls are visible.

### Changes
- install a small init-script guard in every Playwright browser context, so both market observer and normal bots are covered
- react only to the exact `electronics-verification-pop-up-dialog--overlay`
- additionally require dialog text identifying Electronics Verification before taking action
- prefer the explicit acknowledgement button (`Rozumiem`, `Got it`, `I understand`)
- safe fallback only to an explicitly labelled `Zamknij`/`Close` button inside that same overlay
- never force-click through the overlay and never click an arbitrary page/modal button
- MutationObserver makes the handler work when the popup appears after navigation or later DOM updates
- add JUnit4 regression tests for selector/label scoping

### Safety
- no negotiation, target, quota or RealActionGuard behavior changes
- no broad modal dismissal
- no generic page-wide button matching
