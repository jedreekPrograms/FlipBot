## Description

## Summary
- make `FlipBotPlaywrightApplication` the single normal entry point for workers, market stats, and the controlled fingerprint/load/behavior fleet
- add `ControlledTestModuleManager` so `FLIPBOT_TEST_AUTOMATION=true` starts the guarded test fleet in the same process
- keep test-only modules fail-closed: invalid or production targets are skipped without stopping normal FlipBot startup
- stop simple controlled mode from implicitly attaching fingerprint lab restrictions to every normal `BrowserManager` context
- make PRICE_PROBE fail closed to disabled state when its configured test target is forbidden/malformed, so the rest of FlipBot can still start

## Safety boundary
- fingerprint fleet remains limited by `FingerprintLabPolicy` to loopback / `*.localhost` / `.test`
- PRICE_PROBE still rejects `vinted.pl` and subdomains
- advanced BrowserManager fingerprint integration still requires the explicit `FLIPBOT_FINGERPRINT_RUNTIME_INTEGRATION=true` flag

## Intended UX
Normal usage is one Run action: `FlipBotPlaywrightApplication`. Test-only modules start automatically when their controlled configuration is enabled and valid; otherwise they log BLOCKED/SKIPPED and the normal application continues.
