## Description

## What changed
- replace all-remaining-steps reservation with a 7-day rolling capacity forecast
- model configured rejection waits plus seller concession paths at 5/10/20 percentage points
- stop simulated concession paths at the ~40% Vinted price floor
- reserve future-day capacity, so late-evening starts cannot overload tomorrow
- keep a 12% planning safety buffer, capped at 3 slots (3 slots for the 25/day limit)
- recalculate from currentStep and persisted response/step timestamps for active conversations
- retain the existing atomic daily offer quota as the final hard gate before every real submit

## Safety
The hard daily quota implementation is unchanged. The planner only controls admission of new conversations. Every first offer and every next step still calls the backend quota reservation immediately before the real submit, so a 26th daily proposal remains blocked even if the forecasting model is wrong.

- additional-product ladders remain isolated while sharing the same bot quota
