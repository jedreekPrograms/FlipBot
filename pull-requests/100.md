## Description

Fixes the responsive layout regression visible in negotiation counter-offer rules and hardens the rest of the management UI against narrow content areas.

Key fixes:
- restore the intended full-width span for `negotiation-policy-card-wide`,
- remove rigid inner minimum widths from counter-offer reaction rows,
- add component container queries so negotiation rules respond to the actual card width rather than only the browser viewport,
- make page-level form/history/dashboard/action-required/dictionary layouts respond to the actual page width after the sidebar is accounted for,
- make the market observer summary respond to its own card width,
- make the price matrix switch from the 1300px desktop sheet to cards based on the matrix width,
- harden History cards against long values and narrow action areas.

Frontend/CSS only. No API, bot runtime, marketplace, negotiation state, or business-logic changes.
