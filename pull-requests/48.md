## Description

## Goal
Make seller-response handling configurable per negotiation step instead of always escalating immediately.

## Per-step behavior
Each step now configures:
- what to do after a formal Vinted rejection: send next step immediately or wait N hours
- fallback behavior for a seller counteroffer
- any number of counteroffer discount thresholds, where discount is ALWAYS measured from the original listing price
- highest matching percentage threshold wins

Example defaults migrated to existing bots:
- step 1 rejection -> next step immediately
- step 2 rejection -> wait 6h
- step 3 rejection -> wait 12h
- step 4+ rejection -> wait 24h
- seller counteroffer below 10% discount -> wait 6h
- seller counteroffer >=10% discount -> wait 2h
- seller counteroffer >=15% discount -> next step immediately

## Important mechanics
- existing `maxAcceptedCounterOffer` remains highest-priority: a seller price within that threshold goes to ACTION_REQUIRED immediately
- if the seller's price is already at/below our planned next offer, it also goes to ACTION_REQUIRED instead of irrationally offering more than the seller asked
- formal rejection/counteroffer first-detection timestamps are persisted in the backend so 6h/12h/24h timers do not restart on every poll
- a changed seller counteroffer creates a new fingerprint/timer
- new negotiation step resets the old response timer
- delayed rules fail closed if the response timestamp cannot be persisted
- pending/read/normal-message 3h policy remains separate and unchanged
- adaptive pricing/global cap/quota/idempotency/real-action guards remain intact

## Existing bots
Flyway V25 migrates all existing step policies and adds the default 10%/15% rules. Existing negotiations are preserved; no destructive reset is needed.

Response/timing policy fields are safe to edit while active negotiations exist. Prices, accepted-counter thresholds, messages and step structure remain locked while active.

## UI
The bot create/edit step cards now contain a dedicated response-policy editor with:
- rejection action + optional wait time
- counteroffer fallback action
- add/remove percentage rules
- per-rule action and wait time
- explicit explanation that percentages are measured from original listing price
- mobile-responsive styling

## Tests
Adds deterministic Playwright coverage for immediate/delayed rejection, 10%/15% seller concessions, original-price percentage calculation, stable response fingerprints and the never-offer-more-than-seller guard.
