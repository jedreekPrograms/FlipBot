## Description

Runtime logs from the full negotiation audit showed Vinted currently emits seller-message timestamps such as `1.09.2026, 12:27:39`. `ConversationActivityDetector` required `dd.MM.yyyy`, so normal seller messages were detected but their timestamps became null. For PENDING conversations this could incorrectly select the 48-hour no-engagement path instead of the intended 3-hour seller-activity wait.

This change accepts both padded and non-padded Vinted day/month values and adds regression tests for live examples (`1.09`, `1.9`, `10.08`) plus invalid input.

No DB/schema changes.
