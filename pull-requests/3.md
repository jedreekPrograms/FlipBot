## Bezpieczeństwo danych

- usunięcie marki jest blokowane, jeśli marka jest używana przez konfigurację bota
- usunięcie marki jest blokowane, jeśli marka ma jeszcze zapisane modele
- usunięcie modelu jest blokowane, jeśli model jest używany przez konfigurację bota
- usunięcie kategorii jest blokowane, jeśli kategoria jest używana przez konfigurację bota
- rename marki/modelu/kategorii propaguje poprawioną wartość do bezpiecznych konfiguracji botów
- rename jest blokowany, jeśli dotyczy uruchomionego bota albo bota z `NEGOTIATING` / `ACTION_REQUIRED`

## Architektura

`BotConfiguration` przechowuje markę, model i categoryPath jako wartości, a nie FK do słowników. Dlatego rename świadomie aktualizuje również konfiguracje, zamiast zostawiać stare tekstowe wartości.
