## Description

The calendar planner currently counts only non-baseline listings whose first_seen_at falls inside the previous calendar week. That under-reports the weekly market set even when the database already knows many listings that were still present during that week.

This changes the completed previous-week metric to count unique model/listing observations whose observation lifetime overlaps the week (`first_seen_at < weekEnd` and `last_seen_at >= weekStart`). Because market observations are unique per model + marketplace listing id, existing inventory seeds the week once and newly observed ids are naturally added without duplicates. Today/current-week arrival counters remain first-seen/new-listing metrics.

This reuses the historical observation data already stored in the database and requires no migration or tracking reset.
