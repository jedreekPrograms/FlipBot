## Description

Session-stability audit follow-up.

Current stable defaulted FLIPBOT_BROWSER_BLOCK_SERVICE_WORKERS to enabled for headless contexts. That makes an optional RAM optimization affect Vinted authentication/session/challenge behavior unless the operator explicitly opts out.

This restores the compatibility-safe default: service workers remain enabled unless FLIPBOT_BROWSER_BLOCK_SERVICE_WORKERS=true is explicitly configured. The existing catalog/item-detail heavy image/media guard remains enabled, so the broader browser-memory optimization is preserved.

Updated unit coverage locks the opt-in behavior and invalid-value fallback.

No scheduler, negotiation, quota, session-file persistence, login credentials, frontend, or backend changes.
