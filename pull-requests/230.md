## Description

Runtime `nextRunAt` is the eligibility timestamp, not a guaranteed future start time. With catalog concurrency capped, queued jobs can legitimately have an eligibility time in the past while waiting for capacity. The dashboard previously displayed that old timestamp under "Następny job", which looked like the clock was wrong.

This keeps scheduler semantics unchanged and only adjusts the Runtime UI: overdue QUEUED jobs now show "Gotowy do uruchomienia" / "oczekuje na wolny slot". Future schedules and session-blocked retry timestamps remain unchanged.
