## Description

## What changed

- add `offersLast24Hours` to market planning response
- calculate it from existing non-baseline observations with `firstSeenAt > now - 24h`
- expose the field to the frontend
- add a new `Nowe / 24h` column in the Price Matrix
- before the first full 24h has elapsed, show the value with `od startu pomiaru` so the UI does not pretend the rolling window is complete
- keep existing `Oferty / 7 dni` and recommended bot calculation unchanged

## Semantics

The first complete scan is still a baseline and does not count as new supply. After baseline, newly observed listing IDs are counted immediately in the 24h metric. Once the baseline is at least 24h old, the value represents a full rolling 24-hour window.

## No migration required

The feature reuses existing `MarketListingObservation.firstSeenAt` and `baseline`; no schema change is needed.

## Safety

No collector, Vinted interaction, negotiation, real-action, quota, guard, scheduler or bot behavior is changed.
