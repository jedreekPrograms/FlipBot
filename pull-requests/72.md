## Summary
- supersedes closed PR #71 with a clean implementation from current `main`
- keep normal listing ownership and real negotiations unchanged
- add independent PRICE_PROBE records for active `NEGOTIATING` / `ACTION_REQUIRED` listings
- allow probe assignment across all normal running bots regardless of model/target
- exclude the real-negotiation owner from probing its own listing
- enforce one probe per probe-bot/source-listing with a DB unique constraint
- enforce a hard maximum of 15 reserved/sent/unknown probe slots per source listing under a pessimistic listing lock
- generate one of 15 Polish text templates and a randomized lower price (65–85% of the real negotiation's current price, rounded to 10 PLN and always strictly lower)
- persist the exact reference price, generated price and rendered message for later analysis
- FAILED-before-send releases capacity; UNKNOWN remains reserved to avoid ambiguous duplicate sends
- stale CLAIMED probes are cancelled once the source real negotiation is no longer active
- cascade probe rows only when the underlying bot/listing record is actually deleted

## Scheduling / switch
- add independent `PRICE_PROBE` scheduler jobs
- process at most one probe per scheduled bot job to avoid bursts
- `FLIPBOT_PRICE_PROBE_ENABLED=false` is the single feature kill-switch; normal catalog/negotiation jobs continue unchanged
- probe endpoint URL remains ordinary configuration via `FLIPBOT_PRICE_PROBE_BASE_URL`

## Safety boundary
- probe execution is isolated from `RealActionPreflight` and never uses the normal price-offer controls
- the test runtime is scoped to the configured probe endpoint and refuses real `vinted.pl` hosts

## Tests
- backend coverage verifies own-listing exclusion, cross-target assignment and the 15-slot cap
- Playwright config coverage verifies the feature-off boundary and endpoint mapping
