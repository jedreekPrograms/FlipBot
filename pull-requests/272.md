## Description

## Goal

Protective/test branch only. Stable is intentionally left unchanged until runtime testing confirms this does not disturb Vinted flows.

## What changes

- Adds a conservative network-level blocker for the exact advertising/RTB families observed in the visible popup chains: `3lift.com`, `4dex.io`, `adtrafficquality.google`, `doubleclick.net`, `googlesyndication.com`, `openx.net`, `pbstck.com`, and `seedtag.com`.
- The blocker applies to headed LIVE mode as well as headless jobs, so ad documents/scripts are aborted before their redirect chain can load.
- Vinted, Cloudflare challenge, hCaptcha, Google reCAPTCHA and gstatic reCAPTCHA traffic remain allowed.
- Strengthens the existing pre-navigation popup guard:
  - makes `window.open` difficult for page scripts to replace;
  - blocks arbitrary named new browsing contexts, not only `_blank`;
  - respects `<base target>`;
  - guards imperative `form.submit()` / `requestSubmit()` paths that can bypass the regular `submit` event.
- Keeps the existing reactive `BrowserContext.onPage()` close as the final fail-safe.
- Adds emergency kill switch `FLIPBOT_BLOCK_AD_TECH=false` so the network blocker can be disabled without reverting code.

## Safety

- No negotiation/session/filter logic changed.
- No Vinted domain is blocked.
- CAPTCHA/challenge infrastructure is explicitly covered by tests as allowed.
- Unknown/malformed URLs fail open.

## Tests

Adds policy regression coverage for all observed ad-tech domains, lookalike domains, Vinted and challenge traffic, plus stronger popup-script assertions.
