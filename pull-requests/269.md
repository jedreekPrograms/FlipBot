## Description

## What changes

- `Wyświetl sesję` no longer waits for the bot's next scheduled job.
- Playwright scheduler sync defaults to 1s so preview requests are detected quickly.
- A dedicated headed Chromium opens a **read-only clone** of the bot's saved storage state.
- The preview never saves, clears or overwrites `bot-X.json` and never performs interactive login.
- While preview is requested, that bot's normal scheduler work is paused.
- If a normal job was already running when preview was requested, it is allowed to finish first; the preview opens only after that job releases session ownership.
- `Ukryj sesję` waits for the preview browser to fully close on its owner thread before normal bot jobs can resume.
- If preview shutdown times out, the bot stays paused rather than risking two browsers using the same account session.

## Safety properties

1. One session owner per bot at a time.
2. No second normal worker can claim a paused bot.
3. Existing in-flight job is never interrupted.
4. Preview is read-only with respect to persisted production storage state.
5. Scheduler due work is preserved and resumes after preview closes.

## Tests

Adds scheduler tests proving a preview-paused bot cannot be claimed and that an already-WORKING job may finish without requeueing until preview ownership is released.
