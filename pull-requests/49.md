## Fix
The discount threshold input used `min="0.001"` together with `step="0.1"`.

For HTML number inputs, valid stepped values are calculated from the minimum, so the browser accepted values like `4.901` and `5.001` but rejected clean values such as `5`, `10` or `15`.

The threshold input now uses `step="any"`, while preserving the existing backend/frontend range validation (`> 0` and `<= 100`). This allows normal integer thresholds like 5%, 10%, 15%, as well as decimal thresholds when wanted.
