## Description

## What changed
- add a dedicated market-statistics observer card above the normal Bots table
- create/edit/delete the observer from a small credentials-only form (name, Vinted e-mail, password)
- observer has no bot configuration, target, quota or negotiation steps
- hide the observer from all regular bot repository reads so it cannot be started, edited or deleted through normal bot endpoints
- keep the observer in the shared `bot` table only for encrypted credentials, a globally unique bot/session id, and safe session isolation

## Automatic collector
- remove the need for `FLIPBOT_MARKET_STATS_BOT_ID`
- Playwright now resolves the currently configured observer through the backend
- market-statistics collection is enabled by default and can be disabled with `FLIPBOT_MARKET_STATS_ENABLED=false`
- first observer check occurs about 30 seconds after Playwright starts
- if no observer exists, the collector stays idle and polls again; creating the observer in the frontend does not require changing the Run Configuration
- successful full scans remain spaced by the configured interval (24h by default)
- failures retry after 15 minutes without affecting normal bot workers

## Isolation
- the observer remains `STOPPED` in the normal bot domain and is never returned by normal `/api/bots` repository reads
- normal RUNNING bots can operate at the same time as the observer collector
- no real-offer, next-step, quota, persistent guard, or negotiation processor logic is changed
