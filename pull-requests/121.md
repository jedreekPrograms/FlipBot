## Description

Presentation-only redesign of the existing premium skin. Restores a bright/white visual direction while keeping all application behavior intact.

Visual direction: light Linear × Attio × Stripe × Vercel.

Highlights:
- white translucent sidebar with grouped navigation, vector icons and premium active states
- layered warm-white application background with subtle ambient gradients
- refined typography, spacing and visual hierarchy
- elevated KPI surfaces with restrained hover/motion
- polished buttons, segmented controls, forms and custom selects
- dense high-readability Bots and Runtime tables
- clearer status, quota, cooldown and session-block treatments
- refined Action Required, History, Dictionaries, bot forms and pricing matrix
- premium modal/backdrop treatment
- responsive mobile navigation and card/table conversion
- reduced-motion accessibility support

Scope is intentionally limited to `frontend/src/styles/premium-ui.css` plus three presentation strings in `AppLayout.tsx`. No API, backend, persistence, scheduler, quota, negotiation or business-logic changes.
