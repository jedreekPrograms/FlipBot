## Description

Keeps `stable-local-2026-08-28` untouched and applies two narrow fixes on top of the protected PR74-based snapshot.

Session refresh:
- recognize Vinted `/session-refresh` URLs explicitly;
- wait for transient session refresh before continuing;
- recover a stale persisted homepage session once so LoginService can perform a clean login;
- require real home/catalog readiness instead of treating `/session-refresh` as success.

Cross-bot negotiation ownership:
- preserve per-bot discovery, so several bots may still see/evaluate the same marketplace listing;
- add a global `(marketplace, marketplace_listing_id)` negotiation claim before FIRST_OFFER;
- a temporary pre-submit claim blocks the competing bot only for that attempt;
- once the first offer is confirmed, ownership becomes durable;
- NEXT_STEP also verifies the same global owner, so an already-existing duplicate negotiation cannot continue from a second bot;
- migration backfills existing negotiations and deterministically keeps the oldest backend listing as owner, marking competing active duplicates `SKIPPED_ALREADY_NEGOTIATED`;
- add focused cross-bot guard regression tests.

Base remains the protected stable snapshot; no PR75+ feature set is being merged wholesale.
