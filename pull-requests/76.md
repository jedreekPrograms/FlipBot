## Description

Improves handling of the Vinted human-verification screen without attempting to bypass it.

Changes:
- recognizes the Polish slider challenge shown as “Potwierdź, że jesteś człowiekiem” / “Przesuń w prawo, aby zabezpieczyć dostęp”
- pauses bot actions and waits for manual completion
- raises the default manual-verification window from 3 minutes to 10 minutes
- supports `FLIPBOT_HUMAN_VERIFICATION_TIMEOUT_SECONDS` (bounded to 60–1800 seconds)
- requires three consecutive clean polls after the challenge disappears before resuming, avoiding mid-transition races
- adds regression coverage for the Polish slider text

No CAPTCHA solving, slider automation, fingerprint spoofing, or new stealth mechanism is added.
