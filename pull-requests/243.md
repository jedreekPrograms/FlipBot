## Description

Full-audit stability fix prompted by bot 10 / Samsung Galaxy S25 FE listing 10034864145.

The negotiation check could navigate directly to a conversation, land on Vinted `/session-refresh`, and immediately validate the refresh URL as if it were the conversation URL. That caused the conversation check to fail before acceptance/counteroffer processing.

This change exposes the existing bounded/retrying MarketplaceNavigator path for arbitrary trusted Vinted URLs and routes four production flows through it:
- existing negotiation conversation inspection;
- next-step negotiation preparation/send;
- first-offer item navigation;
- live listing target verification.

The shared navigator keeps cookies/storage intact, waits up to the existing session-refresh timeout, retries boundedly, rejects non-Vinted targets, and does not alter negotiation prices/decisions, quota, session files or submit semantics.

Regression coverage reproduces the UUID S25 FE conversation URL through `/session-refresh` and verifies recovery without touching stored session state.
