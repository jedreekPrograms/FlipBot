## Description

## What changed

- add optional `marketMinPrice` / `marketMaxPrice` to dictionary models and the Price Matrix
- show `Min obserwacji` and `Max obserwacji` next to the existing pricing fields
- pass those bounds to every market-observer discovery strategy, including category/text and text-only fallbacks
- keep blank bounds unrestricted, matching the current observer behavior
- calculate 24h / 7d offer counts and recommended bot demand from the newly bounded observation stream
- reset only that model's market baseline when its observer price range changes
- reject stale observation batches if the range changes while a scan is already running, with pessimistic model-row locking to close the race
- trigger an early baseline scan after a reset instead of waiting for the normal 24h interval; real collection failures still keep the existing 15-minute backoff

## Price-filter hardening

- make both `price_from` and `price_to` resilient to Vinted UI failures by applying exact URL fallbacks when necessary
- verify the actual numeric URL values, not merely the presence of the parameters
- preserve the newest-first fallback from PR #35

## Session recovery from the attached runtime log

The latest runtime log repeatedly failed before the observer could scan any model because Playwright could not restore an IndexedDB entry from the saved storage state (`Unable to restore IndexedDB`).

This PR:
- stops persisting IndexedDB in future session state files
- detects this specific stored-session restore failure
- invalidates the unusable session and starts a clean browser context so normal login can rebuild the session
- does not swallow unrelated browser/context failures

## Data semantics

Existing models migrate with both bounds as `NULL`, so behavior is unchanged until a bound is entered. Changing the bounds intentionally clears that model's previous market observations and starts a fresh baseline because historical observations do not store the listing price that was valid at the time.
