## Description

## What changed

- add one reusable styled `AppSelect` and replace the native selects used by Runtime, bot filters, dictionary creation and dictionary management
- render dropdown menus through a portal so they are not clipped by scroll containers; keep them inside the viewport and automatically open upward when there is not enough space below
- add a restrained commercial UI layer with consistent spacing, radii, input sizing, focus states, cards, buttons and responsive safety rules
- make the desktop sidebar collapse into a compact sticky mobile navigation below 980px
- make Runtime filters responsive and convert the wide Runtime table into labeled cards on smaller screens
- make the Bots table convert into labeled cards instead of relying on horizontal scrolling on small devices
- make bot filter forms scale 3 columns -> 2 columns -> 1 column and keep selected-model pricing/reference information readable
- rebuild `Dodaj model` as a stable 2-column form that becomes one column on narrow screens so help text and labels stay readable
- rebuild model-management rows so category / edit / delete controls do not drift or overflow as the viewport narrows
- keep existing Price Matrix responsive behavior and add outer overflow safeguards
- polish form action layouts, long text handling and scrollbars

## Design intent

This deliberately stays close to FlipBot's existing visual language: neutral navy/white admin UI, subtle borders and shadows, no flashy gradients, no unnecessary animations and no decorative features that would make the product feel like a different app.

## Responsive behavior

- desktop: current sidebar/table-first workflow remains
- <=1240px: dense 3-column forms reduce to 2 columns
- <=980px: sidebar becomes mobile navigation; Runtime/Bots tables become cards; dictionary management stacks cleanly
- <=740px: forms and filter/reference grids become one column
- <=520px: actions and card fields stack vertically for phone widths

## Safety / scope

- frontend only
- no backend, database or Playwright changes
- no negotiation logic changes
- no real-action flag, offer limit or submit behavior changes
