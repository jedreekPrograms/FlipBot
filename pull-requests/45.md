## Description

## Goal
Replace the blanket "no editing while active negotiations exist" rule with field-aware edit restrictions.

The bot must still be STOPPED before any edit is saved, so Playwright never reads a configuration while it is being changed.

## Editable while NEGOTIATING / ACTION_REQUIRED listings exist
- bot display name
- minimum listing price
- maximum listing price
- daily negotiation budget
- global automatic negotiation cap (`maxAutomaticOffer`)

The global cap may be lowered, but never below the highest price already sent in any active negotiation.

## Locked while active negotiations exist
- Vinted e-mail
- Vinted password
- marketplace
- category
- brand
- target mode
- model / search query
- adaptive-pricing mode toggle
- negotiation-step count/order
- step offer prices
- accepted-counteroffer thresholds
- step messages

These fields define account identity, listing target, or the meaning of `currentStep`; changing them mid-conversation could make an existing negotiation inconsistent.

## Backend
- add `/api/bots/{botId}/edit-capabilities`
- return `hasActiveNegotiations` and `minimumNegotiationCap`
- validate only critical-field changes when active negotiations exist
- allow safe operational fields without replacing negotiation-step entities
- requeue `SKIPPED_OUTSIDE_PRICE_RANGE` when the price range changes
- continue requeueing `SKIPPED_OFFER_TOO_LOW` when pricing behavior materially changes

## Frontend
- Edit Bot page enters a limited-edit mode when active negotiations exist
- critical controls are individually disabled instead of disabling the whole form
- global cap remains editable and shows the minimum allowed value based on already-sent active offers
- explanatory messages show exactly why each locked section is locked

## Tests
Added backend unit coverage for:
- safe operational edits with an active negotiation
- rejecting a cap below an already-sent offer
- rejecting target/model changes
- rejecting negotiation-step changes
- rejecting Vinted account changes
- edit-capability calculation across NEGOTIATING and ACTION_REQUIRED listings
- preserving full structural editing when there are no active negotiations
