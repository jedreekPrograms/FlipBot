## Description

Full-audit rollback regression fix.

The exact-category protection from #224 had disappeared after the stable rollback. CategoryNavigator was again using generic role-name matching, which can match similar accessible names.

This restores fail-closed category selection without reintroducing the old raw selector path:
- category options are clicked through native Playwright `getByRole(BUTTON, name, exact=true)`;
- category-only behavior changes; brand/model selection stays on its existing specialized logic;
- a bounded 350ms settle is added between category tree levels so Vinted can render the next level before its exact wait starts;
- existing 3-attempt retry and URL `catalog[]` persistence verification stay unchanged;
- no fuzzy fallback is allowed.

Regression coverage verifies the category path uses the exact-option primitive and never falls back to generic selectOption/waitForOption.
