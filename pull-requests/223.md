## Description

## Co zmienia
- dodaje ulotną flagę `sessionPreviewRequested` per bot po stronie backendu
- przekazuje flagę przez istniejący sync RUNNING botów do Playwrighta
- wybrany bot uruchamia swój normalny następny job z `headless=false`
- pozostałe boty pozostają zgodne z globalnym `schedulerHeadless`
- `Ukryj sesję` przywraca headless dla kolejnych jobów bez przerywania bieżącego
- nie tworzy dodatkowego browsera/job-a i nie zmienia `SessionManager` ani persistence sesji
- czyści preview request, gdy bot przestaje być RUNNING
- dodaje kontrolki Runtime UI oraz testy lifecycle rejestru/backendu

## Ważne zachowanie
Już trwającego headless joba nie da się odsłonić w połowie bez restartowania jego runtime. Dlatego kliknięcie `Wyświetl sesję` obowiązuje od następnego normalnego joba tego bota. Jest to celowo bezpieczniejsze dla aktualnej sesji i marketplace action.

## Bezpieczeństwo
- last-known-good session bez zmian
- brak zmian w `SessionManager`
- headed runtime nie jest utrzymywany po zakończeniu joba
- preview jest process-local i znika po restarcie backendu
