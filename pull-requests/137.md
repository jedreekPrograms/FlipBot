## Description

The market-stats observer was aborting before the first model scan because prepareObserverCatalogSession() performed a second full Page.waitForLoadState() after MarketplaceNavigator.goToCatalog(). goToCatalog() already navigates with DOMContentLoaded and waits for the catalog shell, while Vinted can leave non-essential resources loading long enough for Playwright's full LOAD wait to time out.

This removes that redundant full-load wait so the observer can proceed to model scans using the existing catalog readiness checks.
