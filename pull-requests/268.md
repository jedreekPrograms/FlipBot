## Description

## Required behavior split

### VINTED_MODEL
- The native Vinted model filter is authoritative.
- Listings may start negotiations only when they are present in the CURRENT exact native model-filter scan.
- No seller-title, URL-slug, structured Model, item-page or existing-conversation target safety guard is allowed to veto that native-filter result.
- Persisted backlog rows outside the current exact scan are deferred until they reappear; they are not re-verified by a separate guard.

### SEARCH_QUERY
- Search results remain safety-guarded.
- Catalog/title/URL/live item verification stays active.
- The final already-open offer page is checked again against the configured search query before quota/submit.

## Model checkbox fix
- Model discovery now inspects only canonical `role=button` rows, not title/suffix children mixed together.
- The exact canonical row that proved the model is kept instead of resolving a page-wide stale `.first()`.
- The exact `...--suffix` is resolved inside that row.
- Selection tries the exact suffix via Playwright click, DOM click and physical mouse click, verifying the exact native checkbox after every attempt.
- Exact input/row/keyboard fallbacks remain bounded.
- Model option settle timeout increases to 15s to tolerate Vinted filter debounce/render delays.

This preserves exact separation between S25 / S25 FE / Ultra / Edge while removing the unintended post-filter safety gate from native Vinted model mode.
