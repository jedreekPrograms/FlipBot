## Description

## Problem
Vinted can render a privacy/cookie overlay on an already authenticated page (including inbox/conversation views). The current login-only OneTrust selector does not cover the newer banner whose primary action is `Zgoda na wszystkie`, so the overlay can intercept normal Playwright clicks.

## Fix
- add reusable `CookieConsentHandler`
- recognize the current Polish `Zgoda na wszystkie` CTA plus common CMP/English variants and the legacy OneTrust id
- invoke consent handling from the shared human-verification gate used across catalog, item-page and negotiation flows
- re-check consent while a verification wait is in progress, because the banner may appear after navigation/challenge transitions
- never click `Wybierz niezbędne` / cookie-management controls
- add unit tests for the current Polish banner label and false-positive controls

The handler is best-effort and does not treat absence of a cookie banner as an error.
