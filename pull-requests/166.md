## Summary
- keep `fix/session-refresh-stable` untouched at stable `100ebca`
- add an Expo/React Native mobile shell for the same FlipBot web UI
- bundle the existing Vite frontend into Spring Boot static resources on the mobile branch
- have the app connect directly to `http://<PC-IP>:8081`
- Spring Boot serves both the exact web panel and the existing `/api` endpoints
- no separate Vite/Node server is required on the PC during normal use
- external links such as Vinted still open in the system browser
- add SPA route forwarding so refresh/navigation works when the panel is served by Spring Boot
- add CI/typecheck plus an automated frontend bundle refresh for this feature branch

## Runtime on PC
Only the existing processes are required:
1. Spring Boot backend on 8081
2. Playwright

The phone talks to the backend over the local network. A one-time Windows Firewall allow rule for private-network TCP 8081 may be required.
