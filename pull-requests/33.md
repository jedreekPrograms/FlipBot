## Description

## Problem

Po PR #32 observer zaczął poprawnie próbować wszystkie modele, ale log z realnego uruchomienia pokazał kolejny blocker: `VINTED_MODEL` potrafi kliknąć model, po czym Vinted nie utrwala `brand_collection_ids[]`. Dla iPhone 13 pierwszy skan przez to kończył się błędem i frontend pozostawał na `Czeka na pierwszy skan`.

Dodatkowo filtr category/brand jest elementem UI Vinted i może być chwilowo niestabilny. Market observer nie powinien tracić całego modelu tylko dlatego, że jedna ścieżka filtrowania UI zawiodła.

## Nowe zachowanie

Collector ma teraz warstwowe strategie discovery:

1. `DICTIONARY_FILTERS`
   - zachowuje dokładną semantykę słownika,
   - `VINTED_MODEL` nadal najpierw próbuje category + brand + model Vinted.

2. `CATEGORY_TEXT_FALLBACK`
   - tylko gdy dokładny `VINTED_MODEL` zawiedzie,
   - zachowuje category + brand,
   - przełącza discovery na SEARCH_QUERY po nazwie modelu,
   - strict matcher nadal decyduje, co faktycznie jest liczone.

3. `TEXT_ONLY_FALLBACK`
   - ostatnia warstwa awaryjna, gdy UI filtrów dalej jest niestabilne,
   - wyszukuje `marka + model` bez category/brand UI,
   - strict matcher wymaga wtedy tokenów marki i modelu,
   - oczywiste akcesoria są odrzucane.

Legacy modele bez kategorii nadal używają wcześniejszego brand + text fallbacku, ale jeśli nawet filtr marki zawiedzie, mogą zejść do text-only zamiast zostać pominięte.

## Shutdown safety

`InterruptedException` w cause chain nie uruchamia żadnego fallbacku. To oznacza shutdown/przerwanie procesu i jest propagowane zamiast maskowane kolejnymi próbami.

## Frontend

Frontend nie wymaga zmiany: Price Matrix już odświeża `/planning` co 15 sekund. Po udanym baseline wiersz zmienia `Czeka na pierwszy skan` na `Zbieranie danych 0/7 dni`. Liczba `Oferty / 7 dni` pozostaje celowo ukryta do zebrania pełnego 7-dniowego okna, ponieważ baseline nie jest liczony jako nowe oferty.

## Zakres

Zmiana dotyczy wyłącznie `MarketStatsCollector`. Nie zmienia normalnych botów, negocjacji, real actions, quota, guardów ani schedulera produkcyjnych botów.
