## Description

Prevents the popup/ad-tech storm one layer earlier than the existing reactive tab closer.

Changes:
- adds a central host-based AdTechRequestBlocker for known advertising/RTB infrastructure
- explicitly blocks AdaptMX/a-mo.net, including euw2-sync.a-mo.net
- installs BrowserContext.route(...) for every bot context so matching iframe/fetch/script/image/navigation requests are aborted before remote network access completes
- keeps the existing preemptive window.open/_blank suppression and single-page popup guard as independent fallback layers
- uses exact host/subdomain matching to avoid blocking Vinted, its CDN hosts, or arbitrary third-party traffic
- rate-limits ad-block logs to avoid console spam
- adds regression tests for a-mo.net, common ad hosts, Vinted/CDN allow cases, lookalike domains, malformed URLs, and log throttling

No backend/database changes.
