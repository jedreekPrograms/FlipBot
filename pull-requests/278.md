## Description

Performance-only audit changes with session safety kept out of scope.

- reuse the outer headless Playwright/Chromium runtime only while another scheduler task is already ready
- keep every scheduled job in its own BrowserContext and keep existing validated bot-X.json restore/save flow unchanged
- force a runtime relaunch if headless/headful mode changes
- close a retained runtime promptly when the ready queue drains
- skip two negotiation-list backend reads in normal catalog runs; preserve them for one-shot safety mode
- add focused tests for browser retention, scheduler ready-work hints, and one-shot measurement behavior

Intentionally unchanged: LoginService, SessionManager, JobSessionPersistence, session-refresh handling, storage-state validation/backups, session-block cooldown logic.
