## Description

### Why
Fresh headed-runtime behavior showed two separate issues:

1. the market-statistics collector already works against the public Vinted catalog without interactive login, but the UI/backend still treated it as a credential-bearing Vinted account, unnecessarily reserving an e-mail that could be used by a normal negotiation bot;
2. ad/RTB tabs such as `wp.pl` could still visibly appear because the existing `BrowserContext.onPage()` guard only closes a popup after Chromium has already created the tab.

### Changes
- replace the observer credential form with a read-only anonymous collector card
- remove observer create/update/delete API operations and obsolete credential DTO/client code
- add Flyway V30 to clear the current observer e-mail/password while preserving its technical row/id; create a credential-free system observer only if none exists
- backend never exposes observer credentials to Playwright
- `BotContext` recognizes `Anonymous Market Observer` and deliberately refuses to restore or save `sessions/bot-<id>.json`, so an old authenticated observer session cannot keep using the released Vinted account
- install a BrowserContext init script before the first page is created; it suppresses `window.open`, `target=_blank` links/areas and `target=_blank` form submissions before ad/RTB scripts can create a visible tab
- retain the existing immediate `onPage` close guard as a second line of defense
- add regression tests for popup suppression policy and anonymous observer session isolation

### Safety
- normal negotiation bots still restore/save their own sessions
- no offer/quota/idempotency/target logic changes
- external subresources/iframes are not network-blocked, so CAPTCHA/CDN/API behavior is left intact
- observer remains strictly read-only and account-free
