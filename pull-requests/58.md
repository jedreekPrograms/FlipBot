## Description

### What changed
- market-stats observer now probes a restored authenticated session once and otherwise immediately continues anonymous read-only catalog collection; it no longer spends up to 60s on an unnecessary interactive login
- first root category option gets the same 10s render window as later category steps, avoiding repeated reloads seen in the live logs
- VINTED_MODEL final verification is now reported as exact-filter verification, does not count a fake item-page request, and does not apply item-page pacing when no detail navigation happens

### Live-log evidence
- normal bot scheduler was healthy and parallel (two worker slots, working=2)
- no Vinted rate-limit or popup-storm event was present
- observer successfully recorded model scans after falling back to anonymous mode
- repeated first-attempt category timeouts and the observer's 60s login wait were avoidable overhead

### Safety
- no backend, database, frontend, quota or real-action guard behavior changed
- exact VINTED_MODEL fail-closed semantics remain unchanged
- anonymous observer state is still never saved over a stored authenticated session
