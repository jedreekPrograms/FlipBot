## Description

## Problem

Po PR #13 pojawił się nowy problem przy równoległym runtime: dodatkowa karta mogła powstać jako pusty `about:blank`, zostać zachowana przez popup guard, a następnie nawigować do reklamy. Guard klasyfikował ją tylko raz — przy `BrowserContext.onPage` — więc późniejsza nawigacja nie była ponownie sprawdzana. W skrajnym przypadku mogło to prowadzić do lawiny reklam/popupów bez czytelnych logów o ich zamykaniu.

Drugi problem widoczny w logach: przy 2 RUNNING botach startowało od razu 10 headful Chrome runtime'ów, ponieważ każdy worker slot tworzył `BrowserManager` jeszcze przed otrzymaniem pierwszego joba.

## Zmiany

### Popup storm protection (`BotContext`)
- nowy popup nadal może chwilowo rozpocząć jako pusty/about:blank
- na każdej dodatkowej stronie rejestrowany jest `Page.onFrameNavigated`
- po nawigacji głównej ramki strona jest klasyfikowana ponownie
- Vinted URL pozostaje dozwolony
- jednoznacznie zewnętrzny URL jest zamykany
- maksymalnie 2 dodatkowe strony mogą być otwarte równocześnie
- po ponad 10 zdarzeniach nowych stron w jednym krótkim bot-jobie włącza się `POPUP STORM` hard limit i każda następna dodatkowa karta jest zamykana natychmiast
- główna karta bota nigdy nie jest zamykana przez guard

### Lazy browser startup (`BotWorkerSlot`)
- slot nadal jest długowiecznym wątkiem
- `BrowserManager`/Playwright/Chrome nie są tworzone przy samym starcie slotu
- Chrome jest uruchamiany dopiero po przejęciu pierwszego joba przez dany slot
- BrowserManager nadal pozostaje przypisany do tego samego slot-thread i jest później reuse'owany
- przy 2 aktywnych botach nie powinno już startować 10 nieużywanych Chrome'ów tylko dlatego, że `FLIPBOT_WORKER_COUNT=10`

## Safety

PR zmienia wyłącznie:
- `BotContext.java`
- `BotWorkerSlot.java`

Nie zmienia:
- filtrów
- target matchingu
- negocjacji
- quota
- scheduler semantics / DelayQueue
- runtime telemetry API
- real-offer flags

Realne oferty i next steps pozostają wyłączone w scheduled mode.

## Co sprawdzić po merge

1. Uruchomić `FlipBotPlaywrightApplication` z 2 RUNNING botami.
2. Powinny wystartować slot threads 1..10, ale BrowserManager/Chrome dopiero dla slotów, które faktycznie coś claimują.
3. Jeśli pojawi się popup zaczynający od about:blank i przejdzie na zewnętrzny URL, log powinien pokazać `Closing unexpected browser page ... extra page navigated, external URL`.
4. Jeśli strona zacznie generować lawinę popupów, powinien pojawić się `POPUP STORM detected`, po czym kolejne dodatkowe strony są natychmiast zamykane.
