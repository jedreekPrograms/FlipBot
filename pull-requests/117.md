## Description

Finishes the hard-session-block flow after PR #116.

- adds session-block fields to `/api/dashboard/runtime`
- shows `SESSION BLOCKED`, total blocked duration, retry attempt and live retry countdown directly on the Runtime bots table
- renames the generic counter to `Błędy z rzędu`
- resets stale generic consecutive failures once a hard Vinted session/IP block is positively classified
- keeps the original `sessionBlockedSince` and escalating 15m -> 30m -> 1h -> 2h... episode semantics
- strengthens the global run-executor fallback by polling the current Vinted page briefly before converting a login/navigation failure into a generic `RUN_FAILED`; this catches block pages that finish rendering just after the login exception
- adds a backend regression test for reclassification/reset and persistent episode start

No schema change beyond already-applied V34.
