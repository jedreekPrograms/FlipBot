## Description

Fixes the failure pattern seen when several running bots start work concurrently:

- keep `PriceProbeTestStealthProfile` out of normal `CATALOG_SCAN` and `NEGOTIATION_CHECK` browser contexts; it is now installed only for `PRICE_PROBE` jobs
- make `MarketplaceNavigator` treat Playwright `TimeoutError` / `Timeout ... exceeded` as retryable navigation failures, so the existing 3-attempt recovery logic actually covers the observed 30s homepage timeouts
- retry the normal login/session check once when Playwright times out while the Vinted page is still loading
- preserve the existing ad-tech request blocker and normal marketplace flows

Observed runtime symptom: bots with free negotiation capacity had `realOffers=true` but `CATALOG_SCAN` died while opening the Vinted homepage before scanning any listings.
