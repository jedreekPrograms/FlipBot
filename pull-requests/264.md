## Description

## Problem

Vinted can render model search results so both the selectable row and a nested title node match the prefix
`selectable-item-brand_collection-`.

The current code accepts the known `--title` suffix as exact model evidence, but then clicks whichever exact locator was selected. That can click the text/title node instead of toggling the model checkbox. The UI then shows the exact model but leaves the checkbox empty.

## Fix

- Treat `--title` nodes as identity/text evidence only.
- Resolve the proven collection id back to the canonical row:
  `selectable-item-brand_collection-<id>`.
- Prefer the checkbox inside that exact row:
  - native `input[type=checkbox]`,
  - then role=checkbox,
  - then row label,
  - finally the historical exact-row click fallback.
- If a semantic checkbox exists, require a confirmed checked/selected state before clicking "Pokaż wyniki".
- Final persistence remains fail-closed: the catalog URL still has to contain the exact proven `brand_collection_ids[]` value.
- No fuzzy model matching is introduced; S25 / S25 FE / Edge / Ultra remain distinct.

## Regression

Adds a test proving title-child evidence is canonicalized back to the base selectable row id.
