## Description

Consolidates the previous fingerprint-defense lab and guarded BrowserManager bridge into one local/test-only laboratory.

Highlights:
- coherent named synthetic profiles
- centralized lab configuration
- optional AES-256-GCM profile session persistence for cookies/localStorage
- first-party lab cookie lifecycle observations
- optional local/test-only mouse/scroll/typing simulation
- optional proxy routing restricted to loopback / reserved `.test` hosts
- bounded multi-context load/isolation harness (up to 1000 total contexts, max 100 active per batch)
- expanded fail-closed policy tests and profile/cookie tests
- updated `.env.example` and lab documentation

Safety boundary remains hard: lab-instrumented contexts can reach only loopback, `*.localhost`, `.test` and `*.test`; production HTTP(S)/WebSocket targets and external proxy endpoints are rejected. `navigator.webdriver` is observed rather than hidden and native function source is not forged.
