## Description

### Why
Normal worker windows are visible locally when `FLIPBOT_SCHEDULER_HEADLESS=false`, but the market-stats observer had an independent `FLIPBOT_MARKET_STATS_HEADLESS` setting that defaulted to `true`. This made the observer invisible even while debugging normal workers.

The latest runtime log also shows why visual observer debugging is useful: the collector recorded 60/76 targets, while 16 strict exact-model scans failed closed. We should see those failures live before changing model-matching semantics.

### Changes
- when `FLIPBOT_MARKET_STATS_HEADLESS` is unset, inherit `FLIPBOT_SCHEDULER_HEADLESS`
- preserve an explicit observer-only override through `FLIPBOT_MARKET_STATS_HEADLESS=true|false`
- keep the safe default `headless=true` when neither variable is configured
- accept the same common boolean aliases (`true/false`, `1/0`, `yes/no`, `on/off`)
- log which configuration source selected observer visibility
- add unit tests for inheritance, override precedence and defaults

### Expected local behavior
If the normal scheduler is already launched with:

`FLIPBOT_SCHEDULER_HEADLESS=false`

the observer will now launch its own visible Chrome window automatically. To hide only the observer, set:

`FLIPBOT_MARKET_STATS_HEADLESS=true`

No filtering, negotiation, quota, or market-statistics matching semantics are changed.
