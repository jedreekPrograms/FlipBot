## Description

## What
- reuse one process-wide Java `HttpClient` for Playwright -> local backend traffic
- add a 5s connect timeout and 15s per-request timeout
- restore the thread interrupt flag consistently when blocking HTTP calls are interrupted
- move the standalone negotiation-activity client onto the same bounded transport
- add regression coverage for shared-client reuse and both timeout layers

## Why
A stalled local backend/socket could previously pin a worker job and its Chromium runtime without an upper bound. Recreating `HttpClient` objects in short-lived job clients also created unnecessary selector/connection-pool resources. This change bounds HTTP lifetime without changing endpoint or marketplace-action semantics.
