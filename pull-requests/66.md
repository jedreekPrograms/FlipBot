## Full-system audit

This PR applies the remaining fixes found during the full backend + Playwright + frontend + DB/runtime audit.

### Integrity and safety
- adds a durable cross-bot marketplace negotiation claim before FIRST_OFFER, so two bots cannot negotiate the same Vinted listing
- losing per-bot rows become terminal `SKIPPED_ALREADY_NEGOTIATED` before quota reservation or submit
- preserves fail-closed behavior for ambiguous post-submit failures
- fixes explicit bot deletion by cascading historical `bot_command` foreign keys

### Capacity / throughput
- future-step capacity is reserved only for actual `NEGOTIATING` conversations; `ACTION_REQUIRED` no longer consumes automated future capacity
- removes hidden production defaults of 3 first offers / 1 next step per run; backend capacity, daily quota and persistent guards are authoritative unless the operator explicitly configures a runtime throttle
- controlled real-action mode remains capped to one action

### Negotiation behavior
- adds per-step `readWaitHours` and `unreadWaitHours` through Flyway, backend DTO/service/mapper, Playwright DTO/policy and frontend create/edit UI
- keeps backward-compatible defaults of 3h after read and 48h without read
- when a read/unread timer expires, advances to the next configured step if one exists instead of blindly expiring the conversation
- keeps existing formal rejection/counteroffer and seller-message timing semantics intact

### Targeting / regressions
- dedicated `Galaxy Tab S11 Ultra` SEARCH_QUERY tests cover exact/compact spelling and reject S10 Ultra, S11 FE and plain S11
- exact VINTED_MODEL source-of-truth semantics remain unchanged

### Verification
The PR is intentionally not to be merged until Backend, Playwright and Frontend CI are all green. Audit invariants are documented in `docs/audit/FULL_SYSTEM_AUDIT_2026-08-21.md`.
