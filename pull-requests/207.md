## Description

First resource-audit hardening step. Scope is intentionally limited to the Playwright -> local backend transport.

Changes:
- reuse one shared HttpClient instead of creating a transport per ApiClient instance
- reuse one ObjectMapper
- add a 5s connect timeout
- add a 20s request timeout to every backend request
- restore the thread interrupt flag consistently for GET/POST/PATCH when HttpClient.send is interrupted
- add regression tests for shared transport, request timeout and interrupt preservation

No browser lifecycle, scheduler cadence, Vinted navigation, offer logic, market-stats or frontend behavior is changed in this PR.
