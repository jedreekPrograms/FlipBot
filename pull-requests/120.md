## Description

Presentation-only redesign. No API, backend, scheduler, negotiation, quota, persistence or business-logic changes.

Visual direction: Linear × Railway × Attio × Vercel.

Includes:
- redesigned application shell/sidebar with icons and grouped navigation
- dark premium design tokens and consistent visual hierarchy
- refreshed Dashboard cards and period controls
- dense operational tables for Bots and Runtime
- status/quota/cooldown treatments
- unified forms, selects, dictionaries and configuration surfaces
- refreshed pricing matrix, history/action-required surfaces and dialogs
- responsive mobile navigation and card/table behavior
- reduced-motion accessibility support

The new CSS layer is intentionally imported last so existing page behavior and markup remain intact while the visual system is applied consistently.
