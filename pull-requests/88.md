## Description

Stage 7 audit focused on the two intended Vinted targeting modes only: VINTED_MODEL (category -> brand -> exact Vinted model) and SEARCH_QUERY (text search -> category -> brand). No country/location-selection behavior is added.

Current durable fixes:
- reject listing URLs that are not HTTPS on trusted vinted.pl hosts or do not match the expected marketplace listing ID;
- reject conversation URLs that are not trusted Vinted inbox URLs for the expected conversation ID;
- validate backend listing/conversation references at the backend -> Playwright API boundary before target inspection or negotiation;
- add regression tests for relative Vinted URLs, wrong IDs, external/lookalike hosts, HTTP and protocol-relative URLs.

The temporary live public-DOM probe was removed before this PR and is not part of the diff. Audit of negotiation submit/idempotency continues on this branch; merge only after final green CI.
