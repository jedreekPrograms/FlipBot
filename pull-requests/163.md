Changes are isolated to market-stat collection:
- inspect every scanned Vinted listing detail before recording a model scan,
- parse the visible `Dodane ... temu` / explicit publication date,
- refuse to record guessed or partial timestamps,
- store that publication moment in the existing market observation timestamp field,
- count `Dzisiaj`, `Ten tydzień` and `Ostatni pełny tydzień` from the Vinted publication moment, including baseline listings,
- keep normal bot scheduling, sessions, login and CAPTCHA code unchanged.

This PR is intentionally draft until CI passes and the live Vinted detail-page text is verified locally.
