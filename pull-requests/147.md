## Description

## Problem
The current market-stat collector assumes the internal observer row has already been migrated to the exact name `Anonymous Market Observer`. Local FlipBot development keeps Flyway disabled, so V30 may never have normalized or created that row.

When a legacy observer name survives, the backend still returns blank credentials, but `BotContext` does not recognize the bot as the anonymous observer. That means it can restore an obsolete observer storage-state and skips the anonymous UI-stability guard used for public Vinted catalog filtering. The result is consistent with an old baseline remaining in Price Matrix while `Oferty dziś` / `Oferty ten tydzień` stop receiving fresh observations.

## Changes
- make `MarketStatsObserverService` self-heal the internal observer row on read
  - create it automatically when missing
  - force the canonical anonymous name
  - clear legacy email/password
  - keep it STOPPED so it never enters normal bot scheduling
- always return the canonical credential-free observer contract to Playwright
- canonicalize the observer again in `MarketStatsApiClient` as defense in depth, so stale database naming cannot make Playwright restore an old `sessions/bot-X.json`
- add backend tests for legacy-observer normalization and automatic bootstrap

## Expected behavior
`Playwright start -> backend ensures anonymous observer -> collector receives canonical anonymous identity -> BotContext ignores any old observer session -> anonymous Vinted UI guard is installed -> full model pass records observations -> Price Matrix current-window columns update again.`

No negotiation bot behavior or real-action flow is changed.
