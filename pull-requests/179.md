## Description

## Problem
The live market-stats run after PR #178 confirms the exact Vinted upload-date field is now being read correctly. `REL|tygodnia` resolves successfully, but several older listings render the same field as the singular value `roku` with no numeric prefix.

Those `REL|roku` values currently fail parsing, which leaves otherwise complete model scans marked incomplete and schedules unnecessary retries.

## Changes
- Parse the confirmed singular `roku` upload-date value as one year before the observation time.
- Keep all existing exact upload-date extraction, sequential detail navigation, pacing, backoff and fallbacks unchanged.
- Add a regression test for the live `REL|roku` value.

## Runtime evidence
The supplied log shows repeated successful `REL|tygodnia` resolution, while the remaining unresolved IDs fail specifically with `source='REL|roku'`. Models 68, 69 and 71 are consequently recorded incomplete, while models without that edge case complete normally.
