## Description

## Problem

The installed FlipBot Mobile APK can still show `domain undefined` / `net::ERR_NAME_NOT_RESOLVED` when the phone is running an older standalone bundle from before the invalid-host recovery merged in #176. A normal `git pull` on the PC does not update an already-installed standalone APK.

## Changes

- bump FlipBot Mobile to `1.0.1`;
- set Android `versionCode` to `2` and iOS `buildNumber` to `2`, so a rebuilt app is distinguishable from the stale bundle;
- document that the current mobile code rejects persisted `undefined`, `null` and `nan` hosts, clears the invalid saved server address, and reopens connection settings;
- document the difference between updating the repository and updating an installed APK;
- clarify that Tailscale Serve does not need to be reconfigured when the `.ts.net` address already works in the phone browser.

## Scope

No networking behavior or Tailscale configuration is changed in this PR. The invalid-host runtime recovery itself is already present in `mobile/App.tsx` from #176; this change versions that recovery so the installed build can be identified and updated reliably.
