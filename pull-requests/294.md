## Description

## Goal

Keep the public FlipBot repository buildable while moving key Vinted conversation-inspection implementation into the private `jedreekPrograms/flipbot-playwright-core` repository.

## Moved out of the public repository

The private core now owns:
- live negotiation-event DOM classification,
- seller counteroffer card scoping,
- seller counteroffer plausibility checks,
- read-only live item-price modal inspection,
- seller-message/read-indicator DOM inspection,
- Vinted-specific activity JavaScript.

The public repository keeps only orchestration, backend state, quotas/guards and a reflection bridge.

## Runtime behavior

The real `FlipBotPlaywrightApplication` refuses to start without the private core implementation.

On an authorized Windows machine:

```powershell
cd playwright
.\bootstrap-private-core.ps1
```

The script:
1. clones/updates the private repository under `.private/`,
2. runs its tests,
3. installs its Maven artifact locally,
4. creates the ignored `.private-core.enabled` marker,
5. activates the private Maven dependency.

No GitHub token or private source is committed into the public repository.

## Public CI

The public project compiles through `PrivateVintedCoreBridge` without a compile-time dependency on the private artifact. Vinted DOM implementation tests moved with the implementation into the private repository.

## Safety preserved

No changes to:
- daily quota / capacity,
- persistent action guard / idempotency,
- negotiation decision rules,
- strategy snapshots/versioning,
- terminal recovery,
- scheduler ownership,
- seller counter price semantics,
- read/message/rejection timing policy.

The public orchestration still executes the same human-verification hook on every private-core poll.
