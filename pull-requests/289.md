## Description

## Behavior change

When adaptive negotiation is enabled and the seller sends a formal Vinted counteroffer through "Zaproponuj cenę":

- seller counteroffer <= maxAutomaticOffer
  -> immediately mark the listing ACTION_REQUIRED
  -> show it in "Oferty do kupienia"
  -> do not send any further automated negotiation step

- seller counteroffer > maxAutomaticOffer
  -> keep the existing negotiation policy / next-step behavior

Static/non-adaptive mode keeps the existing per-step "Akceptuj kontrofertę do" thresholds.

## Example

Global negotiation cap: 1450 PLN
Seller formal counteroffer: 1400 PLN

Result: ACTION_REQUIRED at 1400 PLN immediately, even if the current step's per-step accepted-counter threshold is lower and later negotiation steps still exist.

## Safety

This only changes the decision for a formal SELLER_COUNTER_OFFER. It does not auto-buy anything; it only surfaces the listing for manual purchase. No further offer is sent after the ACTION_REQUIRED decision.

Includes regression tests for:
- 1400 <= 1450 -> ACTION_REQUIRED
- 1500 > 1450 -> existing negotiation continues

Frontend help text now documents this rule.
