## Problem
The market-stats collector now reaches iPhone 12 and opens unresolved listing details sequentially, but Vinted can render the exact upload-date field as `godziny` with no numeric prefix. Those rows are currently logged as `Vinted publication label could not be parsed`, which leaves the model incomplete even after the detail traversal finishes.

## Changes
- parse confirmed live Vinted value `REL|godziny` as one hour before observation time
- keep existing numeric hour parsing (`8 godz.` etc.) unchanged
- add a focused regression test for the singular live-DOM value

## Scope
Only the Vinted publication-time parser and its unit test are changed. No scan pacing, filtering, traffic-backoff, session, or negotiation behavior is modified.
