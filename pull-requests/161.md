## Description

## Problem
Fresh runtime logs show the anonymous market observer reaching Vinted, but the OneTrust preference-center overlay (`.onetrust-pc-dark-filter` / `#onetrust-policy-text`) intercepts category-filter clicks. As a result, exact VINTED_MODEL targets fail before any scan/publication-time backfill can be recorded, so PR #160 correctly leaves `published_at` unknown and the calendar counters stay at 0.

## Changes
- restore the narrow OneTrust preference-center guard that was previously proven in PR #149 and got lost when stable was rolled back to the 2026-09-06 base
- handle standard accept-all, `accept-recommended`, and OneTrust's own save/close controls
- bounded 500 ms poll catches preference-center state changes that do not emit a useful DOM mutation
- do not remove overlays or force-click through them
- add regression coverage

## Scope
No changes to session files, login semantics, CAPTCHA handling, negotiation logic, market counting semantics, or publication-time parsing.
