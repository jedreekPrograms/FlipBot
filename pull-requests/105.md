## Summary
- add a simple three-variable controlled test runtime:
  - `FLIPBOT_TEST_AUTOMATION=true`
  - `FLIPBOT_TEST_URL=<loopback / *.localhost / *.test>`
  - `FLIPBOT_TEST_BOTS=1..350`
- reuse the existing fingerprint/session/human-behavior lab stack without requiring the advanced flag set
- make the bounded load harness default to 350 logical test contexts in simple mode, processed in batches of 25
- keep the production boundary fail-closed through the central `FingerprintLabPolicy`, network routing guard, runtime integration guard and interaction guard
- add stable profile cohorts for controlled multi-bot tests
- document the simple mode and keep the old advanced lab variables for compatibility

## Safety boundary
This PR does **not** enable the lab on Vinted or arbitrary production sites. Controlled targets remain restricted to loopback, `*.localhost`, `test` and `*.test`; outbound HTTP/WebSocket escapes remain blocked.

## Motivation
The existing lab was safe but configuration-heavy. This makes the common owned-test-platform workflow understandable: set one controlled URL, choose fleet size, enable the test runtime.
