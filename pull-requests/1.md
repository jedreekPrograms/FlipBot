## Description

## Co zmienia ten PR

- dodaje stronę edycji bota pod `/bots/:botId/edit`
- dodaje przycisk `Edytuj` dla zatrzymanych botów
- pobiera pełną konfigurację bota przez `GET /api/bots/{id}`
- zapisuje zmiany przez `PATCH /api/bots/{id}`
- wykorzystuje istniejące sekcje formularza tworzenia bota zamiast duplikować UI
- podczas edycji hasło jest opcjonalne; puste pole zachowuje obecne hasło
- odtwarza kategorię, markę, model/search query, ceny, strategię ofert, budżet i kroki negocjacji
- pokazuje komunikaty 409 z backendu, np. gdy bot ma aktywne negocjacje

## Bezpieczeństwo

Frontend pozwala wejść w edycję tylko dla bota `STOPPED`, a backend nadal pozostaje źródłem prawdy i blokuje zapis przy aktywnych `NEGOTIATING` / `ACTION_REQUIRED`.

## Walidacja
