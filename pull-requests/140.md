## Description

Replaces the fixed `1 bot = 35 new conversations/week` planning assumption with measurements from the completed calendar week.

- counts the exact previous Monday-Sunday opportunity set from market observations
- intersects that set with unique confirmed `FIRST_OFFER` audits by `marketplaceListingId`, so the Price Matrix shows `started / opportunities` for the same listings
- keeps today and current-week conversation-start counters
- calculates realised conversations per bot from the completed week
- scales the observed bot pool to full opportunity coverage with `ceil(opportunities * existingBots / started)`
- does not invent capacity when the completed week has no confirmed starts or when a full week is not available
- removes the hardcoded 35 conversations/week note from the UI
- adds calculator and service tests for empirical throughput, deduplication, bot/model filtering, and exact opportunity intersection
- no database migration required
