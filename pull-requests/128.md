## Summary

Ports the valid timestamp parsing fix from the old stacked PR #114 onto a clean branch based directly on the current `main`.

Vinted may emit seller-message timestamps such as `1.09.2026, 12:27:39`. The current parser requires a zero-padded day (`dd.MM.yyyy`) and therefore fails to persist the seller activity time for those messages.

### Changes

- accept one- or two-digit day/month using `d.M.yyyy, HH:mm:ss`
- keep invalid/unrecognized timestamps fail-closed as `null`
- add regression coverage for current, zero-padded, single-digit day/month and invalid formats

No schema changes. No unrelated code from the old stacked branches is included.
