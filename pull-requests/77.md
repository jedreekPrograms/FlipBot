## Description

Adds an opt-in browser-fingerprint profile strictly for the configured PRICE_PROBE test origin.

Changes:
- new `FLIPBOT_PRICE_PROBE_TEST_STEALTH_ENABLED` switch, default false
- when enabled, requires `FLIPBOT_PRICE_PROBE_ENABLED=true`
- validates the configured `FLIPBOT_PRICE_PROBE_BASE_URL` through the existing PRICE_PROBE host guard
- refuses `vinted.pl` and all subdomains
- injects the profile into BrowserContext, but the script exits immediately unless `location.origin` exactly equals the configured test origin
- test-only profile adjusts `navigator.webdriver`, language exposure, `window.chrome.runtime`, and notification Permissions API behavior
- other origins keep the normal browser profile
- regression tests verify exact-origin scoping and Vinted rejection

This is intended only for testing anti-automation behavior on a controlled test page; it does not change the profile on Vinted.
