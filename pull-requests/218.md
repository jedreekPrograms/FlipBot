## Description

Adds a safe A/B browser-engine switch on top of stable dd06588b.

- keep system Google Chrome as the default browser engine
- when FLIPBOT_BROWSER_USE_PLAYWRIGHT_CHROMIUM=true and headless=true, try Playwright's bundled/default Chromium headless runtime without channel=chrome
- if that browser is unavailable or launch fails, automatically fall back to the existing system Google Chrome path
- headed/manual mode never opts into this path
- preserve native popup-blocking restoration and all existing Playwright default args
- add config tests for opt-in/default/headed behavior

This is intentionally opt-in so Vinted compatibility/fingerprint behavior is not changed by the merge itself. It enables direct RAM A/B measurement.
