## Description

Adds an opt-in interaction-pacing profile strictly for the configured PRICE_PROBE test endpoint.

Changes:
- new `FLIPBOT_PRICE_PROBE_TEST_HUMAN_PACING_ENABLED` switch (default false)
- hard-scoped through existing `PriceProbeRuntimeConfig`; pacing runs only when the current URL is on the exact configured non-Vinted endpoint
- slower character-by-character typing for test login credentials and probe messages
- bounded random pauses around typing, clicks, hover, and page settle
- scroll-into-view + hover before clicks for realistic UI pacing
- no additional fingerprint spoofing or anti-bot bypass logic
- regression tests verify the pacing scope rejects Vinted and other origins

Optional tuning variables:
- `FLIPBOT_PRICE_PROBE_TEST_KEY_DELAY_MIN_MS`
- `FLIPBOT_PRICE_PROBE_TEST_KEY_DELAY_MAX_MS`
