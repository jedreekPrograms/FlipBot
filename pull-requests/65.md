## Description

## What changed
- keep Playwright's normal Chrome launch defaults except for `--disable-popup-blocking`
- restore Chrome's native popup blocker so automatic ad-tech popup storms are rejected before they become visible tabs
- keep the existing BotContext single-page guard as a second line of defence
- add a focused regression test asserting that only the popup-blocking override is ignored

## Why
Fresh screenshots show top-level tabs to `*.safeframe.googlesyndication.com`, `wp.pl`, `ap.jiji.com` and similar ad/redirect destinations flashing immediately before browser-context shutdown. Playwright itself launches Chromium/Chrome with `--disable-popup-blocking` by default, which explains why ad-tech can create far more popup Pages than a normal Chrome session would permit. Closing pages in `BrowserContext.onPage` happens after page creation, so it cannot guarantee that a headed Chrome tab never flashes.

## Intentionally unchanged
- no Vinted target matching changes
- no negotiation, quota, pricing, login, observer, DB or real-action changes
- no broad ad-domain blocklist
