## Description

Resource optimization on top of stable 257732c3.

- block service-worker registration in headless BrowserContexts by default
- keep headed/manual BrowserManager behavior unchanged
- allow fast opt-out with FLIPBOT_BROWSER_BLOCK_SERVICE_WORKERS=false
- keep existing storage-state restore, login/session handling and route policy unchanged
- add pure unit coverage for default/override behavior

This also makes BrowserContext.route() coverage more predictable because Playwright routing does not intercept requests handled inside a Service Worker.
