## Description

Stage 13 removes one obsolete public REST controller that bypassed the current guarded real-action lifecycle.

Finding:
- `/api/negotiations/offer-sent` and `/api/negotiations/result` were still registered Spring endpoints from an older negotiation architecture;
- no frontend, Playwright, README path, or current repository client uses these endpoints;
- the old service behind `/result` can directly change listing currentStep/status/price without the persistent real-action guard, quota reservation, browser submit confirmation, or real-action audit used by the current system;
- `/offer-sent` can also flip awaitingSellerResponse without browser evidence.

Fix:
- remove only the legacy `NegotiationController`, so those mutation endpoints are no longer exposed;
- leave active negotiation configuration/planning/capacity classes untouched;
- legacy internal classes are not part of this PR because removing dead code is lower priority than eliminating the reachable mutation bypass.

Scope: one backend file removed. No current Playwright/frontend API call changes, no DB migration, no selector or marketplace-flow changes.
