## Description

The dedicated market-statistics observer was still able to inherit a legacy local observer identity when Flyway had not normalized the database row. That meant Playwright could treat the observer like a normal account, restore `sessions/bot-<id>.json`, and skip the anonymous observer UI guards that stabilize Vinted's public catalog filters.

This change:
- self-heals the backend observer row to the canonical `Anonymous Market Observer` identity on every read
- clears legacy credentials and forces the technical observer to `STOPPED`
- recreates the observer row automatically if it is missing
- canonicalizes the observer again in the Playwright API client as defense in depth
- keeps normal bot sessions untouched
- adds backend tests for legacy-row normalization and missing-row bootstrap

The existing BotContext logic then correctly refuses to restore/save a Vinted session for the observer and enables the observer-only cookie/model UI stability guard. This is targeted at the market-stats failures where the observer could not render/select `Elektronika` while normal authenticated workers could.
