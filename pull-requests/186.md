## Description

## Problem
Disabled additional products intentionally remain available to Playwright while an existing negotiation is still `NEGOTIATING`, so that conversation can continue with its original strategy. The shared-budget edit guard, however, validated only currently active additional products. That allowed the main bot configuration to reduce the account-wide daily negotiation budget below the ladder size of a disabled product whose negotiation was still running.

## Changes
- validate the shared daily budget against all active additional products
- additionally validate disabled products that still own a `NEGOTIATING` listing
- continue ignoring disabled historical products once they no longer have runtime negotiation work
- keep duplicate-target validation unchanged: it still compares the main target only with currently active additional targets
- add regression tests for disabled-negotiating and disabled-historical products

## Safety
This preserves the existing design invariant that a product ladder participating in runtime negotiation work cannot be longer than the bot's shared daily action budget, without making old historical rows block future edits.
