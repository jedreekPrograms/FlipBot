## Description

Adds a local-only browser fingerprint laboratory for defensive research without changing FlipBot's production marketplace runtime.

Highlights:
- standalone `pl.flipbot.playwright.lab.fingerprint` package; no imports into BrowserManager/BotContext/login/scanner/negotiation code
- explicit `FLIPBOT_FINGERPRINT_LAB=true` gate
- hard target allowlist: loopback, `*.localhost`, and reserved `*.test` hosts only
- HTTP(S) routing aborts external requests
- Service Workers blocked so they cannot bypass request interception
- WebSockets routed separately; only allowed lab hosts can connect
- self-contained loopback detector server on `127.0.0.1:18091`
- baseline-vs-synthetic Chrome comparison
- synthetic lab profile covering navigator, screen/DPR, locale/timezone, WebGL and canvas surfaces
- deliberate tamper marker and no native-function-source forgery, so defensive checks can detect hooks
- detector page checks UA Client Hints, window-vs-worker consistency, API integrity, webdriver, media/capability signals, WebGL and canvas
- policy and safety regression tests
- PowerShell usage guide in `playwright/FINGERPRINT_LAB.md`

The lab intentionally does not provide production-site stealth or CAPTCHA/anti-bot bypass behavior.
