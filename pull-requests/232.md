## Description

Production logs (excluding manually-operated bot 8) show two safe-failing negotiation races: direct inbox navigation can be validated while Vinted is still on `/session-refresh`, and prepared next-step verification can reject a conversation immediately after a successful dry-run preparation.

This does not relax real-action checks. HumanVerificationHandler now waits up to 15s only for Vinted's trusted session-refresh route to resolve and fails closed if it remains stuck or leaves Vinted. PreparedNextStepStateVerifier then allows up to 3s for the URL to stabilize to the exact expected conversation ID before validating price and submit state. On failure it reports expected ID, actual ID and URL. Guard/quota and exact price checks remain unchanged.
