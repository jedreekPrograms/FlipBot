## Description

## Problem
Current runtime logs prove that `Galaxy S25` could resolve to the `Galaxy S25 Edge` Vinted row because a highlighted child span was treated as an exact label. The downstream target matcher then tried to repair the wrong catalog semantically.

## Fix
- make Vinted model-row matching fail closed and never trust highlighted leaf fragments
- add regression coverage for fragmented `Galaxy S25` + `Edge` DOM text
- separate target semantics: `VINTED_MODEL` trusts the exact persisted Vinted model filter; `SEARCH_QUERY` keeps intelligent title/URL/detail matching
- skip semantic item-title inspection in `VINTED_MODEL`
- make market-stats collection preserve dictionary target mode and refuse text-search fallback for `VINTED_MODEL`

This restores the intended contract: exact Vinted filter means exact model selection followed by processing the Vinted result set; search-query mode performs semantic verification.
