## CAPTCHA flow
`CAPTCHA_REQUIRED -> phone: Rozwiąż CAPTCHA -> PC opens headed bot-X.json session -> LoginService reaches the real visible challenge -> mobile state READY -> user holds TRZYMAJ -> PC moves the slider only while fresh hold heartbeat exists -> user releases -> mouse up -> challenge clears -> session saved -> bot resumes`

The hold control is deliberately fail-safe: Playwright requires a recent phone heartbeat for every movement tick and releases the pointer when that heartbeat expires.

## Mobile app
The same frontend remains available on desktop. On mobile it can be installed as a standalone PWA and exposes all existing pages through the full navigation drawer, with Dashboard / Runtime / CAPTCHA / Bots as primary bottom-navigation destinations.
