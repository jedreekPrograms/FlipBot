## Description

A session-refresh timeout could clear a logged-in browser's cookies and storage. An unsafe job ending also restored the previous rotating backup over the fresh authenticated pre-job checkpoint. Unfinished CAPTCHA then retried as a generic failure after 60 seconds.

This PR preserves cookies/storage through bounded navigation retries, retains the current checkpoint when the final browser state cannot be saved, and gives visibly unfinished CAPTCHA a distinct 15-minute cooldown for all jobs of that bot. Healthy saves, manual CAPTCHA completion, explicit block detection, session preview, and adaptive capacity remain available. Existing session-file installation and backups are unchanged.

The supplied afternoon log confirms those failure paths but starts after the reported overnight logout, so this does not claim to identify that original event. The CAPTCHA cooldown is in the running scheduler, not a new persistent backend status.

Validation: 12 focused regression tests added for navigation, real checkpoint files, verification outcomes, and worker cleanup/all-job cooldown. Full CI required before merge. No live account or marketplace actions were used for tests.
