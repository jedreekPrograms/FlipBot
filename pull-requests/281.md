## What this fixes
- reject stale Observer writes with tracking-generation checks across observations, publication timestamps and publication-window completion
- calculate demonstrated FIRST_OFFER throughput per dictionary model instead of attributing a multi-product bot's total traffic to every model
- use a more conservative 75th percentile of active model days with a 5/day fallback
- remove the obsolete fixed 5/day planning path from MarketStatsService
- expose real Observer health from scan state instead of a permanently green UI dot
- respect custom Observer refresh cadence when deciding whether health is stale
- relax the RAM free-space guard from 5 GiB to 2 GiB while retaining the 82% pressure threshold
- hide irrelevant analytics filters/sections/charts for Observer-only vs History-only modes
- clear stale analytics data after failed filter requests
- make manual date-range precedence visible
- wrap chart legend/footer on narrow screens
- style incomplete-scan warnings in Price Matrix

## Safety
