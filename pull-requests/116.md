## Description

Adds dedicated handling for Vinted's hard session/IP block page (`Twoja sesja została zablokowana`).

- detects Polish/English session-block evidence separately from generic rate limiting
- persists the start of a block episode and its detection count per bot
- retries with 15m -> 30m -> 1h -> 2h -> 4h -> 8h... backoff
- keeps the original blocked-since time across retry attempts and clears it only after a successful full scheduled job or explicit idle/stop
- pauses all scheduled job types for the blocked bot
- prevents per-conversation exception handling from swallowing bot-wide Vinted rate/session blocks
- exposes runtime session-block fields through the existing runtime endpoint
- shows live `Sesja zablokowana`, elapsed block time, attempt number, and retry countdown in the Bots table
- adds regression tests and V34 schema migration

Important for the current local `flipbot_pr74` setup: Flyway is intentionally disabled, so V34 must be applied manually before running the updated backend.
