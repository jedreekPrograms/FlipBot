## What changed
- dictionary models now store `VINTED_MODEL` / `SEARCH_QUERY`
- existing models migrate safely to `VINTED_MODEL`
- dictionary models store optional proposed bot price and expected resale price
- added a dedicated pricing endpoint that does not mutate bot configuration
- added **Cennik modeli**: spreadsheet-like, brand-grouped reference price matrix
- Create Bot now always selects a dictionary model; its target mode is derived automatically
- SEARCH_QUERY models use the dictionary model name as the Vinted search phrase
- Create/Edit Bot shows proposed offer, resale price, and indicative difference
- Edit Bot resolves both VINTED_MODEL and SEARCH_QUERY bots through the dictionary

## Safety
- changing model name/target semantics still requires affected bots to be STOPPED and without active/action-required negotiations
- editing reference prices does not alter existing bot strategy or negotiation steps
- reference prices are informational only; they never auto-fill or submit offers
- existing dictionary models default to VINTED_MODEL via Flyway migration
