## Description

Presentation-only UI refinement. This removes the heavier 3D/glass treatment from the current light theme and replaces it with a much flatter, lighter workspace visual system.

Changes:
- flat white surfaces and neutral page background
- removes decorative ambient gradients and glass effects
- removes card lift/3D shadows and hover elevation
- tighter, lighter sidebar/navigation states
- slimmer controls, tables and status badges
- softer borders and reduced radius
- simplified buttons, forms, selects, dashboards, bot/runtime tables, history, action-required, dictionaries and pricing
- keeps a small modal shadow only where visual separation is functionally useful
- preserves responsive/mobile behavior and reduced-motion support

Scope: only `frontend/src/styles/premium-ui.css`. No component, API, backend, persistence, scheduler, negotiation, quota or business-logic changes.
