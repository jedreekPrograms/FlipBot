## Description

## Problem

Current category selection requires `role=button + exact accessible name` for every hierarchy level. Production logs show the first levels succeed, while leaf categories such as `Telefony komórkowe` and `Tablety` repeatedly time out even though Vinted renders them.

This breaks catalog scans across multiple bots and also Market Stats.

## Fix

- Keep the preferred exact accessible-button path.
- Add a bounded fallback for Vinted leaf-category DOM variants.
- Fallback requires:
  - exact visible text,
  - a known clickable ancestor,
  - exactly one visible clickable exact match.
- Similar/parent labels remain rejected; there is no substring/contains fallback.
- Keep the original timeout budget instead of waiting another full timeout after the button lookup.
- Add regression tests proving `Telefony komórkowe` does not match `Telefony komórkowe i komunikacja`, and `Tablety` does not match `Tablety i akcesoria`.

The change does not touch session persistence, login, real-action guards, quotas, or negotiation logic.
