## Description

Audit follow-up for negotiated offers that may fail to reach ACTION_REQUIRED when Vinted changes the Polish grammatical form of the own-offer status.

- Preserve existing PENDING/ACCEPTED/REJECTED semantics.
- Recognize stable Polish stems so `Zaakceptowane`, `Zaakceptowano` and `Oferta zaakceptowana` classify as ACCEPTED.
- Explicit `Niezaakceptowane` remains UNKNOWN/fail-closed.
- Rejection/pending grammatical variants are handled with the same narrow stems.
- Added focused unit coverage.

No price thresholds, negotiation timing, real submit, quota, session, scheduler, backend API, or frontend behavior changes.
