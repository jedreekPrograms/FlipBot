## Description

Fixes PRICE_PROBE jobs that were failing immediately with `Listing exposes no supported message-seller action.` after opening a listing.

Changes:
- wait up to 20s for either the existing message composer or a usable contact action after DOMContentLoaded
- keep the existing known data-testid selectors and add strict Polish/English semantic fallbacks
- support a direct conversation link when the listing exposes one
- keep the existing composer/send selectors used by normal negotiation chat
- emit visible button/link diagnostics when contact discovery still fails
- log probe assignment and SENT/FAILED/UNKNOWN outcome details in Playwright
- add regression tests for contact-label/test-id classification

No backend schema/allocation changes; listing URLs continue to come from the existing `Listing.url` field.
