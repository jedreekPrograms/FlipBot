## What changed
- market-stat scans now honor each dictionary model's target mode instead of forcing SEARCH_QUERY
- VINTED_MODEL targets use the existing FilterService to apply category + brand + Vinted model + newest-first sorting
- SEARCH_QUERY targets use text search, then category + brand + newest-first sorting
- dictionary models can now store their Vinted category; new models require one
- existing dictionary models can have their category assigned from Manage Dictionaries
- legacy models without category metadata temporarily fall back to a uniquely matching existing bot configuration
- unresolved targets are skipped instead of being scanned globally
- V20 resets the old market-stat baseline because it was collected under the previous incorrect targeting behavior

No negotiation, real-action, quota, or normal scheduler behavior is changed.
