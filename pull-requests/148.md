## Problem
The anonymous market observer starts correctly, receives all 76 targets and opens the public Vinted catalog, but the first Apple target stalls while navigating the category path. The runtime log shows the root `Elektronika` row being selected, then `Tablety, czytniki e-booków i akcesoria` timing out because `CategoryNavigator` only resolves category options through `role=button`.

Vinted's anonymous catalog can render nested category rows as a different DOM element even though the exact category label is visible, so the observer never reaches listing scanning and never records fresh `Oferty dziś` / `Oferty ten tydzień` observations.

## Changes
- keep the existing semantic `role=button` category lookup as the preferred path
- when that lookup fails, fall back to Playwright exact visible-text matching for the requested category label
- never use substring category matching
- add a small settle delay between category levels so the next nested level can render
- keep the existing end-to-end `catalog[]` URL persistence check, so a fallback click is not accepted unless Vinted actually applies the category path
- add regression coverage for exact selector generation/escaping

## Safety
- observer remains anonymous and read-only
- no negotiation, real-action, quota or normal bot scheduler behavior changes
- exact model verification remains unchanged and fail-closed
- category fallback does not invent IDs or accept partial category names
