## Description

Full-audit stability fix.

Catalog/filter code still had three direct Vinted navigations that bypassed the shared MarketplaceNavigator session-refresh handling: sort URL fallback, exact price URL fallback, and FilterActions recovery/reset navigation.

This routes those production Vinted navigations through the same bounded `/session-refresh` wait/retry path already used by negotiation/detail flows. Exact category/model matching, filter verification, retry counts and price/sort semantics are unchanged.

PRICE_PROBE sandbox navigation is intentionally untouched because its runtime explicitly rejects real vinted.pl hosts.
