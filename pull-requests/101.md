## What changed
- remove the global ad-tech request blocker from every Playwright browser context
- remove the preemptive `window.open` / `target=_blank` DOM override from `BotContext`
- keep the existing reactive single-page guard that closes genuinely created extra pages
- keep the Vinted informational-dialog guard and anonymous market-observer UI stability logic
- remove tests that enforced the retired ad-tech/popup interception behavior

## Why
All running bots started receiving the same Vinted restriction screen. The two retired mechanisms globally altered normal page/network behavior and were the most invasive recent changes. This stage restores a much cleaner Chrome/Playwright environment without changing bot scanning, negotiation, quota, session, or real-action logic.

## Scope
Playwright browser/context behavior only. No frontend, backend API, database, quota, or negotiation logic changes.
