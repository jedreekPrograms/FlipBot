## Description

Full-audit security fix.

`GET /api/bots/{botId}/playwright` returns the decrypted Vinted password because the local Playwright runtime needs it. The repository security policy currently permits all requests, so a LAN client that can reach the backend could request that plaintext credential endpoint.

Playwright's backend client is hard-coded to `http://localhost:8081`, so this endpoint can safely be restricted without changing the mobile/web panel:
- require the actual TCP remote address to be loopback (`127.0.0.1` / `::1`);
- reject LAN/non-loopback callers with HTTP 403;
- return `Cache-Control: no-store` for successful credential responses;
- ordinary bot/dashboard/action-required APIs remain unchanged and accessible as before.

Regression coverage verifies IPv4/IPv6 loopback are accepted and LAN addresses are rejected.
