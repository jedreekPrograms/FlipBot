## Description

Protect the existing `sessions/bot-X.json` state from being silently replaced by broken or transient browser state.

- fail closed when an existing session file is empty, malformed, or unreadable instead of treating it as missing
- reject cookie-empty replacement snapshots when the active session still has cookies
- preserve a timestamped last-known-good backup before every validated replacement
- do not persist browser state from failed scheduled jobs, including session-block/login failure paths
- keep the existing staged-write + atomic replacement flow intact
- add regression coverage for zero-byte/malformed active sessions, cookie-loss prevention, and last-known-good backups

This is intentionally scoped to session persistence. Login, scanning, negotiation, observer behavior, and real-action logic are otherwise unchanged.
