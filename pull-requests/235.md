## Description

Hotfix for the current stable branch. Logs showed bot 6 repeatedly re-entering interactive login because its Vinted CAPTCHA/challenge was not positively recognized, so the job exited before `context.saveSession()` and no `bot-6.json` was installed.

Scope is intentionally narrow:
- expand visible human-verification iframe detection to DataDome/captcha-delivery, Arkose/FunCaptcha, Geetest and generic visible captcha/challenge/human iframe markers;
- add a few strong verification texts;
- keep the existing 180s manual-verification wait;
- keep fail-closed behavior: session is still saved only after LoginService subsequently verifies an authenticated Vinted state.

No scheduler, catalog, negotiation, pricing, quota, session storage format, or frontend changes.
