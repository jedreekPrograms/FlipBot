## Description

Performance/scaling follow-up to the live ACTION_REQUIRED visibility fix.

- Adds one read-only `/api/listings/action-required` endpoint backed by a lightweight projection with bot id/name and the listing fields needed by the UI.
- Adds `/api/listings/action-required/count` using a direct status count.
- Action-required page now performs one request per 15s refresh instead of `getBots + one request per bot`.
- Sidebar warning count no longer polls the full dashboard stats calculation.
- Existing per-bot action-required API stays available for compatibility.
- Background polling remains hidden-tab aware and coalesced.

This keeps negotiated offers visible while making polling independent of bot count. No negotiation decisions, price thresholds, quota, sessions, scheduling, or mutation endpoints change.
